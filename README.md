# VIGASHOP - Tienda en Línea
Bienvenido al repositorio oficial de VIGASHOP, una plataforma de comercio electrónico moderna, rápida y segura diseñada para ofrecer la mejor experiencia de compra en línea.

# Características Principales
Catálogo interactivo: Navegación por categorías, filtros de búsqueda y vista detallada de productos.

Carrito de compras: Gestión en tiempo real de productos, cantidades y cálculo de totales.

Proceso de Pago (Checkout): Integración segura para el procesamiento de pedidos.

Diseño Responsive: Adaptado para dispositivos móviles, tabletas y computadoras de escritorio.

Panel de Usuario: Registro, inicio de sesión y historial de compras.

# Tecnologías Utilizadas
Frontend: HTML5, CSS3, JavaScript (o Framework como React / Vue / Angular)
